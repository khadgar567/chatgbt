# Night Monarch — revised master

Standalone Soma Cruz–inspired class. Warlock supplies its chassis.

Download [the revised PDF](Night-Monarch-Revised-Master.pdf) or [the editable Word copy](Night-Monarch-Revised-Master-Editable.docx).

The 40-page source-recovery edition incorporates the uploaded [Markdown revision packet](Night-Monarch-Revision-Packet.md). It retains the revised master's class identity and existing rules, restores the author-confirmed Crimson Elixir without blood points, adds six recovered Jiangshi entries, and recovers two omitted Angeloid clauses. The complete Unison owning source and progression are now available as an explicitly unfinished adapter reference. Genie remains a donor appendix, not a newly granted Night Monarch Brand or companion.

The previous edition's 75 Asura, Jaguar Sun and Rakshasa talent bodies were compared with the recovered source and retained without duplicate catalogues. Original integrated-revision heading boundaries were restored: Banshee's identity is present, and Jiangshi's Hsien-Ko/Unquiet Grave text is separated from Angeloid.

Read the [change ledger](Night-Monarch-Change-Ledger.md) for retained, restored, cut and unresolved dispositions. The original packet preserves copied donor wording, historical labels and all source cells. [Editable content and audits](source/) include the before/after body inventory, exact source-table exhibits and validation report. To rebuild the PDF and Word copy, run `python build_book.py` in that directory with Python, PyMuPDF, ReportLab, python-docx and the system DejaVu fonts installed.

Validation checked all 806 previous content events, 75 complete martial talent bodies, ten source tables, rendered text, text bounds, bookmark pagination, clickable contents and the Word archive. Every page was rendered for inspection. This validates document assembly, not completed game balance.
