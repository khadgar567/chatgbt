# Night Monarch — draft book

Standalone class inspired by Soma Cruz from Castlevania. Warlock is the chassis donor, not the class identity.

The 70-page draft includes all 28 brand/companion sections from the supplied Night monarch.pdf, 27 progression tables, linked contents, and editable Word text.

Author-approved revisions remove the undefined blood-point economy and dependent Infernal Arts. Gargoyle Perfect Defense retains its normal cooldown without a blood-point bypass. Mixed body powers, equipment forms, and independent companions remain as supplied.

This is a rules draft. Master of Night, Dark Lore, base Armament, the Hit Die, conflicting progression descriptions, and source entries with names but no rules remain unresolved. The book labels unfinished entries rather than inventing their mechanics.

Validation checked all 540 progression rows, rendered paragraphs and table cells, text bounds, removal of blood-point rules, and the Word archive. These checks validate document production, not gameplay balance or completeness.
